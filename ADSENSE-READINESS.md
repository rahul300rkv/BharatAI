# Advertising readiness
- No advertising scripts or ad units are installed. Do not enable Auto ads or global ad scripts.
- Keep classroom, generation preview, settings, legal, contact, errors, navigation-only screens and unreviewed lessons ad-free.
- Human-review each public lesson; record real reviewer, date, source and corrections before enabling ads. Current lessons are AI-assisted starter material, not certified reviews.
- Verify actual provider/storage/privacy practices and consent requirements before enabling ads. Use a Google-certified CMP where required.
- Confirm production canonical domain, sitemap, robots, HTTP status, mobile rendering and no ad network requests on excluded routes.
- Configure AdSense site-level exclusions and verify publisher ownership in dashboard; ads.txt is not an ad implementation.
- Run npm install --legacy-peer-deps and npm run build before merge. Approval is Google's decision; no minimum article count is guaranteed.
