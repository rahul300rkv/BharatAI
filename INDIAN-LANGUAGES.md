# Indian language migration
13 Indian languages (Hindi, Bengali, Telugu, Marathi, Tamil, Urdu, Gujarati, Kannada, Odia, Malayalam, Punjabi, Assamese, Maithili) plus English. Native-script selectors and initial core UI strings are available; untranslated UI keys fall back to English. Public editorial lesson text remains English; do not present it as translated. Urdu sets document direction RTL. Voice availability and model accuracy vary. Test real model output, script shaping, mobile RTL, provider-specific voices and all generation routes before release. Do not enable ads on unreviewed translations. Original SVG educational illustrations are schematic and require editorial review alongside lessons. Preserve upstream attribution and license.
